Which classroom tool should I use?

For fair cold calling: use the Random Student Picker with no-repeat mode switched on.

For teacher questioning routines: read the Random Student Picker Guide before using random selection for questions, reading turns or participation checks.

For a classroom display: use the Classroom Wheel of Names when you want the pick to feel visual and shared.

For visual option choices: use the Random Picker Wheel for rewards, activities, prompt types, review games or classroom choices.

For numbered rosters or prompts: use the Classroom Number Picker for a typical class size, or the Random Number Generator for a custom class range.

For class votes: use the Poll Maker when students should choose between several options and see the result.

For discussion prompts: use the Random Question Generator for open classroom questions, or the Would You Rather Generator for clean two-choice questions students can answer, vote on or write about.

For vocabulary and writing: use the Random Emoji Generator for mood prompts and emoji stories, the Random Object Generator for things to describe, draw, sort or find, the Random Letter Generator for phonics, initials and alphabet games, or the Random Word Generator for clean words, writing seeds, spelling games and category sorting.

For speaking games: use the Truth or Dare Generator with the Classroom category and skip any prompt that does not fit the group.

For group activities: use the Random Team Generator to make teams without captain picks.

For order and rotations: use the Fair Rotation Generator when everyone needs a turn, or the List Shuffler to randomise the whole list at once.

Classroom random picker FAQ

Are these classroom picker tools free?

Yes. The classroom tools on Spinnit are free to use and do not require an account.

Do I need to upload my class list?

No. The picker tools run in your browser. Class lists are not uploaded to Spinnit.

Which tool should I use to avoid picking the same student twice?

Use the Random Student Picker and keep no-repeat mode switched on. It works through the class list before anyone is picked again.
