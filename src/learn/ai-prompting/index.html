AI for Complete Beginners: Write Better Prompts

A prompt is simply what you type or say to an AI assistant. This course shows you how to ask clearly, add the details that matter and decide whether the answer is safe and useful. The same approach works with ChatGPT, Claude, Gemini and similar assistants.

Start from the beginning and go at your own pace. Each lesson uses plain language, a realistic example and a short exercise. You can read everything without signing up or saving progress.

What you will learn

Say what you need

Turn a rough idea into a clear request using ordinary language.

Add helpful details

Explain who the answer is for, what it should include and how you want it presented.

Check before trusting

Notice missing information, protect private details and verify important facts with reliable sources.

What happens in each lesson

  1. Understand one idea in plain language.
  2. See an everyday request that is too vague.
  3. Watch it become a clearer, more useful prompt.
  4. Try a small exercise and compare it with an example answer.
  5. Keep one simple idea to use next time.

A clearer prompt can improve the chance of a useful response, but it cannot guarantee accuracy or prevent AI errors. Important information still needs checking.
