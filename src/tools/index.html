What's a "Preset"?

Presets are purpose-built shortcuts for a specific job — for example, 1–100 and 4d6 drop lowest are presets of the main Random Number Generator and Dice Roller. They save you setting up the inputs every time and often add small quality-of-life features (like the D&D stat block roller showing the dropped die, or the No-Repeat Picker cycling through a list without repeats).
