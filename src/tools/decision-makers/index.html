Common Uses

Use decision tools for low-stakes choices like who goes first, what to do, what to eat, what to watch tonight, which task to do next, which game to play, which question to answer, or how to break a tie. For a guided starting point, use the What Should I Tools hub. If the group should vote, start with the Poll Maker. If everyone is happy with the shortlist, use the Random Activity Picker, Random Dinner Picker, Random Movie Picker or another random picker. If the exact job is heads or tails, use the Coin Flip and the Coin Flip Decision Guide for best-of-three and fairness tips. For conversation games, use the Random Question Generator, Would You Rather Generator or Truth or Dare Generator. For important financial, medical or legal decisions, use these only as a prompt for discussion, not as the decision-maker.

FAQ

For two choices, use Coin Flip when you want a heads-or-tails result, or Random Number 1-2 when a number fits better. For group votes, use Poll Maker.
