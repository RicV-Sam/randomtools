Frequently Asked Questions

Can the same number come up twice?

Yes. Each generation is independent, so repeats are possible — especially over many draws. For unique-only picks, shuffle a list and take the first N instead.

Is 1000 included?

Yes. The range includes both 1 and 1000, and every number in between has equal chance.

Can I use this as a giveaway draw?

Yes — the method is fair and unbiased. For a fully auditable draw, record the generation on video, name the range and date, and post the screenshot alongside the winner announcement.
