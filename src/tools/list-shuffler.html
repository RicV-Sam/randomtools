List Shuffler

Paste any list — get it back in a random order

The List Shuffler takes any list you paste in and returns it in a random order using a standard shuffle. You can choose to show only the top N items from the shuffled result, which makes it a simple way to randomly pick or rank items from a larger pool. No limits on list length, no setup required.

How to Use

  1. Paste or type your list into the text area, one item per line.
  2. Optionally set "Pick top N items" to show only the first N results after shuffling.
  3. Choose whether to show numbered positions on each item.
  4. Click Shuffle List to randomise the order instantly.
  5. Use Copy shuffled list to grab the results for use elsewhere.

Common Uses

  • Randomly ordering a playlist, setlist, or queue
  • Shuffling student names to determine random presentation order
  • Randomising a task or to-do list to avoid predictable patterns
  • Picking a shortlist of finalists from a longer list of candidates
  • Creating random tournament brackets for sports or gaming events
  • Assigning random roles or responsibilities within a team

Why Use Spinnit

The Fisher-Yates algorithm is a standard way to shuffle lists fairly for everyday use. Your original list is never stored or transmitted anywhere. Works on any device and requires no account, no installation, and no loading time.

Frequently Asked Questions

Can I pick just the top few items from a longer list?

Yes. Enter a number in the "Pick top N items" field and only the first N items from the shuffled list will be shown. This is useful for selecting a shortlist or picking winners from a pool.

Is there a limit to how long my list can be?

There is no hard limit. The tool handles hundreds of items without any issues. Very large lists may slow the animation slightly, but results are still instant.

Yes, completely free with no sign-up required.
