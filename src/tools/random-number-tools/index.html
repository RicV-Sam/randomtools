Pick a number from any range, jump into common presets, or use number-based random tools for classrooms, games, raffles and quick decisions. Every tool runs in your browser and needs no sign-up.

Best used for

Random number tools work well when every option already has a number: raffle tickets, spreadsheet rows, classroom rosters, game tables, dice-style rolls and quick decisions. If your options are names or text, use a name picker tool instead.
