Random Name Picker

Pick one or more random names online from any list

This random name picker is a quick way to choose from a list without spinning a wheel. Teachers can use it for questions, cold calling, presentation order, classroom games, or choosing helpers. It also works for giveaways, teams, meetings, party games and everyday decisions.

For classroom routines in the US, UK and Europe, keep the rule simple: ask the question, give wait time, then pick. If every student should be called once before repeats, use the Random Student Picker with no-repeat mode or read the random student picker guide.

Pick a random name online

Paste names, participants, entries, tasks or options into the picker and choose how many results you need. The tool returns unique picks from the current list, so it works for one winner, several helpers, a quick meeting order, classroom turns or a small prize draw. If you want a visual reveal, use the Wheel of Names; if you need no repeats across a full round, use the No-Repeat Name Picker.

How to use it

  1. Paste names into the box, one per line or separated by commas.
  2. Choose how many names you want to pick.
  3. Click Pick Name to get a random result.
  4. Use Copy result if you need to paste the chosen name elsewhere.

Classroom examples

  • Pick one student to answer the next question.
  • Run low-stakes cold calling after a short thinking pause.
  • Pick three students for a quick review activity.
  • Choose a presentation order or reading order.
  • Pick a classroom helper, topic, reward or game option.

Giveaways, meetings and games

  • Giveaways: paste eligible entries, set the winner count, and copy the result.
  • Meetings: pick a speaker, demo order, reviewer or next question owner.
  • Games: choose who starts, who joins a team, or which player takes the next turn.

Privacy

Names stay in your browser while you use the page. Spinnit does not require a login and does not upload your list.

Frequently Asked Questions

How do I pick a random name online?

Paste names into the box, choose how many names to pick, then click Pick Name. The picker returns one or more unique names from your list.

Can I use this random name picker in class?

Yes. Paste a class list and pick one or more names for questions, presentations, activities or classroom games.

Can I use it for giveaways or prize draws?

Yes. Paste your eligible entries, remove duplicates if your rules require one entry per person, and pick one or more winners.

Can I use it for cold calling?

Yes, for low-stakes cold calling. Ask the question first, give thinking time, then pick a name. For equal turns, use the random student picker with no-repeat mode.

Are names uploaded to Spinnit?

No. The picker runs in your browser and does not upload your list.

Can I pick more than one name?

Yes. Set how many names to pick and the tool will return that many unique names from the current list.
