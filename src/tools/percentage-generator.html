The Random Percentage Generator produces a percentage or decimal between any minimum and maximum you define, with precision up to three decimal places. You can generate up to 20 values at once and copy the results with one click. Handy for testing, simulations, games, and any scenario that needs a fair random proportion.

How to Use

  1. Set your minimum and maximum values (default is 0–100).
  2. Choose the number of decimal places from 0 to 3.
  3. Set how many values you want to generate at once (up to 20).
  4. Click Generate Percentage to get your result.
  5. Use the Copy button to save the results to your clipboard.

  • Testing data visualisation tools with realistic random percentage inputs
  • Decision-making games where a threshold percentage determines an outcome

Each value is generated in your browser with no data sent anywhere. The result history tracks your recent outputs so you can compare values without taking notes. Works on any device without installation or sign-in, and supports ranges beyond 0–100 for full flexibility.

Frequently Asked Questions

Yes. The decimal places dropdown lets you choose 0 (whole numbers), 1, 2, or 3 decimal places in each generated result.

Can I generate more than one value at a time?

Yes. Set the "How many values?" field to up to 20 and all results will appear together, separated by commas.
