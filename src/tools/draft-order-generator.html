Draft Order Generator

Create a fair random draft order for fantasy leagues, games and group picks

Share card: Generate a draft order, then copy or share it with your league.
Paste your league members, choose snake or linear draft, then generate a random pick order.

The Draft Order Generator creates a random pick order for fantasy football, fantasy basketball, fantasy baseball, sports pools, board game nights, classroom activities, office games and any group where people need a fair first pick. Paste names, generate the order, then copy the result into WhatsApp, Slack, Discord, Teams, email or your league chat.

Use snake draft when each round should reverse, so the person with the last pick in round one gets the first pick in round two. Use linear draft when every round should keep the same order. If you already have a manually agreed order and only want a board view, switch Order mode to Use pasted order.

How to use the draft order generator

  1. Paste every league member, player or team into the box, one per line.
  2. Choose Snake draft or Linear draft.
  3. Set how many rounds you want to display.
  4. Click Generate draft order.
  5. Copy or share the order with everyone before the draft starts.

Fairness note

This tool uses a standard Fisher-Yates shuffle with browser crypto randomness where available. It is designed for everyday, casual and league-fair draft orders. For paid contests, regulated competitions or official league rules, agree the process with participants before generating the order.

Draft order generator FAQ

Can I use this for fantasy football?

Yes. It is built for fantasy football draft order draws, including snake draft boards that reverse every even round.

What is the difference between snake and linear draft order?

A snake draft reverses direction every round. A linear draft keeps the same order every round. Snake drafts are common in fantasy sports because they balance the advantage of picking early.

Can I copy the draft order?

Yes. Generate the order, then use Copy order or Share to send the draft board to your group.

Does Spinnit store the names?

No. The draft order is generated in your browser. Spinnit does not require an account or upload your pasted list.
