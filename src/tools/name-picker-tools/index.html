Best used for

Name pickers are strongest when your input is a list of people, options, teams, tasks or entries. Use a no-repeat picker for rotation fairness, a winner picker for documented draws, a wheel for live reveals, and a list shuffler when you need a full random order.

FAQ

If duplicates in your list should count as extra entries, keep them. If every person should have one chance, remove duplicates first or use a no-repeat picker. For numbered options instead of names, use the random number tools, or return to all random tools.
