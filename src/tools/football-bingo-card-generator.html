How to use it for the World Cup

  1. Use the default event list or add your own football moments.
  2. Generate one card per person or team.
  3. Print cards or copy the text into a chat.
  4. Mark squares when the event happens during the match.
  5. First line, corners, full house or custom rule wins.

Editable for any sport
