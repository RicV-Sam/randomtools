Random Student Picker for teachers — fair classroom turns with no-repeat mode

Paste your class roster, tap once, and keep classroom participation calm, fair, and easy to run.

A random student picker with no-repeat mode is a simple way for teachers to pick a student at random without falling back on the same confident voices. Every student can get a turn before any name appears twice, which helps with cold-calling, reading turns, quick quizzes, and fair participation across a whole lesson. Paste your roster once, tap once per question, and the picker keeps the process visible and easy to accept.

This page is the main classroom picker in Spinnit's Classroom Random Tools cluster. If you want the teaching guidance behind it, read the Random Student Picker guide for teachers or the No-Repeat Student Picker guide.

How teachers use it

  • Cold calling — ask a question, let the tool pick who answers
  • Reading aloud — pick who reads the next paragraph
  • Presentations — decide presentation order fairly
  • Starter activities — pick a student to recap yesterday's lesson
  • Behaviour-neutral calling — removes the perception that you're targeting specific students

Projector tips

The picked name is rendered in large text so it reads from the back of the room. For an even bigger display, press F11 to go full-screen. Names entered in the roster are never sent anywhere — the whole tool runs in your browser.

Build a fair participation routine

Ask the question first, give a few seconds of think time, then pick the student. That keeps the picker supportive rather than stressful. If you want a fuller explanation of classroom routines, use the Random Student Picker guide. If your main concern is avoiding repeat picks across a lesson, use the No-Repeat Student Picker guide.

Frequently Asked Questions

How does no-repeat mode work in the random student picker?

Tick "Don't pick the same student twice" and every student gets called once before any name can be picked again. Once everyone's had a turn the tool announces the round is complete — tap Reset list to start a fresh round.

Is this random student picker fair for cold calling?

Yes. Each remaining student has the same chance on every pick, and no-repeat mode guarantees an equal turn count across the round — removing any perception that you're targeting individuals.

Can I use the student picker on a classroom projector?

Yes. The picked name renders in large text designed to read from the back of the room. Press F11 for full-screen, and the tool works on any device including interactive whiteboards.

Is my class list saved anywhere?

No. The names live only in this browser tab. Close the tab and they're gone — nothing is sent to a server, and no account is required.

What happens when every student has been picked?

The tool announces the list is complete and lets you tap Reset list to start again from the full roster.

Can I use this for a whole-school assembly?

Yes — there's no limit on the roster length, and the picker runs instantly even on a list of several hundred names.
