What is Spinnit?

Spinnit is an independent, free learning and utility site. It helps people build practical AI skills through short lessons, worked examples and browser-based tools, while keeping classroom, workplace, decision and random tools easy to reach.

Learn AI by doing

The Learn AI hub combines practical explanations with worked examples, exercises and checks learners can use immediately. Start with AI Prompting: Beginner to Applied Workflows and complete Lesson 1 without creating an account.

Free browser tools for practical tasks

Use AI Tool Radar to compare tools, the classroom hub for fair participation, workplace tools for team organisation, the football tools hub for group activities, senior-friendly games for accessible play, or the full tools index for every existing utility.

How the tools work

Spinnit lessons and tools run in the browser with no required account. Random utilities support everyday picks, while generated passwords use browser cryptography. Read how Spinnit tools work, the privacy policy, the password security hub, or the randomness and fairness guide for more detail.
