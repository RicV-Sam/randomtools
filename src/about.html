About

Random tools for everyone

Spinnit is a free collection of random generators built for the web. No accounts. No downloads. No nonsense. Just open a tool and use it — on any device, anywhere in the world.

Our mission

🆓
Always free Every tool on Spinnit is completely free to use, forever.
🚫
No sign-up No account, no email, no password — just open and use.
📱
Works on mobile Designed mobile-first and tested on all screen sizes.
🌍
Global Fast worldwide — fully static, no server round-trips.

The tools

Spinnit has core tools for numbers, dice, coin flips, teams, wheels, passwords and names, plus purpose-built presets for specific jobs such as rolling 4d6-drop-lowest for D&D, picking a classroom student without repeats, and drawing a giveaway winner.

Who's behind it

Spinnit is built and maintained by a small independent team based in England. We write the code ourselves, test every tool on the phones we actually own, and read every piece of feedback that comes in. No VC, no agency, no SEO farm — just a free utility site we wanted to exist.

If you've got an idea for a tool we should build, a bug we should fix, or a correction to make — write to us at hello@spinnit.site or through the contact form.

More tools coming soon

We're working on more tools including a random quote generator, new classroom decision tools, creator prompts, and more. Got a suggestion? Drop us a line at hello@spinnit.site — we'd love to hear what you need.

How it's built

Spinnit is built with HTML, CSS, and JavaScript. Tool actions happen in the browser, so names, class lists, generated passwords and random results are not sent to Spinnit servers. The site is static, fast to load, and designed to work on phones, tablets, laptops and classroom displays.

  • No account or login system required
  • No class lists, names or generated passwords stored on Spinnit servers
  • Lightweight pages with no app install needed
  • Privacy details and Google service usage explained in the Privacy Policy
  • Installable as a PWA on mobile and desktop

Editorial principles

Spinnit pages are written to help people choose and use the right tool, not to create thin search variations. We prioritise clear tool instructions, practical examples, honest limitations, and descriptive internal links between tools, hubs and guides. You can read more about how Spinnit tools work and how to think about randomness and fairness.
