    Follow the pictures below. Use a sign-in method you can access again, and keep this guide open while you follow the steps on ChatGPT.

2. Choose one way to sign in

The window we checked offers Google, Apple, phone and email. Choose a method you can use again. You only need one.

Complete the checks shown for your chosen method. If asked to confirm a code or create a password, do that privately on the sign-in screen. Do not type it into Spinnit, an AI conversation or a message to someone helping you.

If a usage-limit message appears

{% set narrationStep = accountGuideNarration.steps[3] %}{% include "partials/account-guide-audio.njk" %}

You have not failed the lesson. Read the notice on your own ChatGPT screen before deciding what to do. This guide does not promise a fixed number of free messages or a reset time for your account.

  1. Look for what is limited. Read whether the notice refers to chatting or a particular feature. This lesson only asks you to write ordinary text messages.
  2. Look for the next available action. If a reset time is shown, note it and return then. If the screen offers a free way to continue chatting, you can use that. If it only offers an upgrade, you can pause instead.
  3. Keep your place. Return to Spinnit and choose “Remember my place on this device”, or write down the step. Choose “Try this task later” if needed. Tick a task only when you have actually done it.

An upgrade offer is a choice to consider later; it is not an instruction from this course to buy anything. Read our free-versus-paid guide before deciding.

What if the page shows an error instead?

A sign-in error, connection problem or blank page is not the same as a usage-limit notice. Check your connection and the website address, then try reloading. If you still need help, use the Help link on the official ChatGPT website and describe the error without sharing a password or verification code.
