How to use ChatGPT on a phone or tablet

Start in your browser, or use OpenAI's official app if you prefer. This guide helps you reach the message box, try one ordinary text request and check the reply.

Use your browser without installing an app

  1. 01Open your usual browser. Type chatgpt.com in its address bar, or use the official website link below. Keep this Spinnit guide open in another tab so you can return to it.
  2. 02Use your existing account if you have one. Choose your usual sign-in method. If you need setup help, follow the account picture guide; it includes a narrow-screen example.
  3. 03Find the message box. If ChatGPT offers Chat and Work, choose Chat for this conversation exercise. You are ready to try the text task below.

Open ChatGPT website (new tab)

A tablet uses the same browser route. Screens and labels may differ from the pictures; follow the wording on your own device.

If you prefer an app, use the official listing

These are the store listings linked from OpenAI's own help pages. Check the listing before installing.

  • iPhone or iPad

    Open the official ChatGPT App Store listing (new tab). The listing checked for this guide names the developer as OpenAI OpCo, LLC.

  • Android phone or tablet

    Open the official ChatGPT Google Play listing (new tab). Look for the publisher OpenAI.

Similar names and logos do not establish who made an app. If the listing is unavailable or your device is not supported, check OpenAI's current help page and the store's compatibility information.

This practice uses the free route

The official app is free to install and offers optional purchases. You do not need a paid subscription for this text exercise. Read any payment screen before deciding; you can pause rather than buy a plan.

After opening the app, sign in with the account and method you normally use. Then find the message box and try the task below.

Try one text conversation

Use this general task without adding names, addresses or other personal details. You can type it yourself; the reply will vary.

Practice request

Suggest a short checklist for packing a bag for a day out. Use plain English.
  1. 01Send the request. Tap the message box, type the request and use the send control.
  2. 02Read the reply. Look for suggestions that fit your day out. Ignore items you do not need.
  3. 03Ask for one change in the same chat. Try “Make the checklist shorter.” Compare the two replies.
How do I know I completed the practice?

You found the message box, sent a request, read the reply and asked for a change. If a suggestion is unsuitable, explain what needs changing and try again. You are practising the controls; the reply does not have to be perfect.

If a reply includes a fact, price, rule or safety instruction you intend to use, follow the answer-checking guide before relying on it.

If you get stuck

The keyboard covers part of the conversation

Finish typing, then use your device's normal control for dismissing the keyboard so you can read the reply. Avoid the Back control if you are unsure whether it will leave the page. Your device's keyboard controls may differ from someone else's.

I cannot find my usual chats or subscription

Check which ChatGPT account and sign-in method you used before. OpenAI's account-on-another-device guidance explains how to identify the account. Do not buy a second subscription just because the first is missing from this screen.

I see a limit or upgrade notice

Read what the notice limits and any next action shown. If a reset time is displayed, note it. You can return later; this guide does not promise a fixed allowance or reset time. Use the usage-limit checklist for help.

I need to return to my Spinnit lesson

If you used the website link above, switch back to the Spinnit browser tab. If you opened the app, return to your browser. Use the same browser and device to resume any practice progress you chose to save.

Useful mobile features

Add permissions only when the task needs them

  • ✓Voice: allow microphone access when you intentionally start a voice conversation; mute or exit when finished.
  • ✓Photos: share a non-sensitive image only when it helps the task. Check the picture for documents, faces, addresses and location clues first.
  • ✓Files: do not upload complete medical, legal, financial or identity documents simply because the button is convenient.
  • ✓Read aloud: response menus may offer a read-aloud option, which is different from having a live voice conversation.

Accounts and payment

Use the account you already have

OpenAI says an existing subscription can be accessed on another device by signing in with the same active OpenAI account. If you purchased through Apple or Google Play, manage that subscription through the corresponding store. Check the first subscription before starting another one on a different platform.

Remember how you signed in

Use the same sign-in method you used originally. If you write a reminder, record the method, such as Google or Apple; keep passwords and verification codes private.
