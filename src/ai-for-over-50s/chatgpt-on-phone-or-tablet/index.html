How to use ChatGPT on a phone or tablet

You can use ChatGPT in a web browser or the official mobile app. The important first step is checking that the app is published by OpenAI, not choosing the first similar-looking result.

Install safely

Use OpenAI's official store listing

  1. 01Open your device's app store. Use Apple's App Store on an iPhone or iPad, or Google Play on Android.
  2. 02Search for ChatGPT. Open the result and confirm the publisher or developer is OpenAI.
  3. 03Check before installing. Similar names and logos are not proof that an app is official. Use the OpenAI help links below if uncertain.
  4. 04Sign in consistently. If you already use ChatGPT elsewhere, use the same account so your eligible plan and chat history can appear across devices.

Do not pay merely to install the official app

ChatGPT has a free plan. A store may offer an optional subscription inside the app, but installation itself should not require buying an unrelated “AI assistant” app.

First conversation

Type one low-risk request

Find the message box, enter a request and use the send control. Start with something you can check yourself.

Try this

Give me a simple checklist for preparing a room before painting. Use plain English, put the steps in order and include common items I may forget.

Continue in the same chat with “Make that list suitable for a small bedroom” or “Which steps need good ventilation?” Check any safety or product instructions against the manufacturer's guidance.

Useful mobile features

Add permissions only when the task needs them

  • ✓Voice: allow microphone access when you intentionally start a voice conversation; mute or exit when finished.
  • ✓Photos: share a non-sensitive image only when it helps the task. Check the picture for documents, faces, addresses and location clues first.
  • ✓Files: do not upload complete medical, legal, financial or identity documents simply because the button is convenient.
  • ✓Read aloud: response menus may offer a read-aloud option, which is different from having a live voice conversation.

Accounts and payment

One subscription can appear on another device—but billing stays with the purchase platform

OpenAI says you can access an existing ChatGPT subscription on another device by signing in with the same OpenAI account. If you purchased through Apple or Google Play, you manage that subscription through the corresponding store. Do not start a second subscription on another platform without checking the first one, because duplicate charges are possible.

Write down how you signed in

“Continue with Apple”, “Continue with Google” and an email-and-password account can lead to different accounts. Use the same sign-in method you used originally.
