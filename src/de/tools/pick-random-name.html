Wählen Sie einen zufälligen Namen

Fügen Sie eine Liste, tippen Sie einmal — eine faire Auswahl in einem Herzschlag

Ihre Auswahl
—

Dies ist der schnellste Weg, um einen zufälligen Namen aus einer Liste im Internet auszuwählen. Kein Konto, keine Pop-ups, keine 30-Sekunden-Rad-Animation — nur einfügen, tippen, fertig. Jeder Name hat eine gleiche Chance, jede Auswahl ist unabhängig, und nichts, das Sie tippen, wird überall gesendet.

Was Menschen dies für

  • Giveaway Gewinner — Fügen Sie Ihre Eintragsliste ein, tippen Sie auf, Screenshot der Gewinner
  • Eisbrecher treffen — "random person shares first"
  • Wer zuerst geht — Spiele, Präsentationen, die den Kaffee macht
  • Secret Santa paarings — Schnellzüge ohne Papierschlupf
  • Auswahl eines Restaurants — Liste der Optionen, lassen Sie die Chance entscheiden
  • Forschungsproben — eine zufällige Antwort aus einer Kurzliste auswählen

Wählen Sie mehrere auf einmal

Brauchen Sie mehrere Gewinner? Set Wie viele? bis zu 50 und das Tool gibt Ihnen, dass viele einzigartige Namen (keine Duplikate innerhalb einer einzigen Auswahl). Tippen Sie erneut auf einen frischen Pick.

Andere Picker-Stile

Für ein animiertes Raderlebnis verwenden Sie die Rad der Namen. Für Klassenzimmer Verwendung ohne Repeat-Schutz, versuchen Sie die No-Repeat Picker oder SchülerUm eine ganze Liste auf einmal zu schütteln, verwenden Sie die Liste Shuffler.

Häufig gestellte Fragen

Ist die Wahl wirklich zufällig?

Ja. Das Tool verwendet den eingebauten Zufallsgenerator des Browsers, der unvoreingenommen und unvorhersehbar ist. Kein Name wird heimlich begünstigt.

Sind Duplikate aus meiner Liste entfernt?

Nein — das Tool behandelt jede Zeile als separater Eintrag. Wenn ein Name zweimal in Ihrer Liste erscheint, hat es die doppelte Chance zu gewinnen, was manchmal ist, was Sie wollen.

Kann ich beweisen, dass die Ziehung fair für ein öffentliches Giveaway war?

Drehen Sie die Auswahl auf oder nehmen Sie einen zeitnahen Screenshot. Posten Sie es mit der letzten Eintragliste und dem Datum. Das ist das gleiche Maß an Transparenz.
