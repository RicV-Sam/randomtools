Aktuelle Ergebnisse

Fünfundzwanzig ist die durchschnittliche britische und US-Klassengröße, die eine zufällige Zahl zwischen 1 und 25 einer der am meisten genutzten Bereiche im Bildungswesen macht. Lehrer verwenden es, um Studenten zu wählen, rufen Freiwillige, entscheiden, wer zuerst präsentiert, oder zufällige Sitzplätze. Diese Seite gibt Ihnen eine saubere, faire Auswahl in einem Hahn.

Handy für

  • Abholung eines Schülers mit Rollennummer von einer Klasse von bis zu 25
  • Zufällige Sitzzuweisungen zu Beginn eines Begriffs
  • Auswahl einer Spaltennummer in einer 5×5 Bingokarte
  • Zufällige Zuordnung von 25 nummerierten Karten oder Aufforderungen
  • Eine Frage aus einer Liste von 25 Review-Fragen

Für größere Gruppen

Eine Klasse von 30 lehren? Versuch Benutzerdefinierte Reichweite und setzen Sie das Maximum auf Ihre Klassengröße. Für namenbasierte Picking statt Zahlen, die Rad der Namen ist der Klassenzimmer-Liebling.

Sonstige Bereiche

Auch nützlich: 1–10, 1–50, 1–100, 1–20.

Häufig gestellte Fragen

Kann ich sicherstellen, dass derselbe Schüler nicht zweimal hintereinander abgeholt wird?

Nicht von einer einzigen Generation — jede Auswahl ist unabhängig. Verwenden Sie die Liste Shuffler auf einer Liste von 25 Namen oder Nummern und arbeiten durch die gedämpfte Ordnung.

Arbeitet das an einem Projektor?

Ja. Das Ergebnis ist groß, kontrastreich und sichtbar von der Rückseite eines Klassenzimmers, wenn projiziert.

Sind Daten gespeichert?

Nein. Die Ergebnisse werden im Browser generiert und nie an einen Server gesendet. Die Geschichte wird deutlich, wenn Sie die Registerkarte schließen.
