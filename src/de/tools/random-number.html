Aktuelle Ergebnisse

Mit dem Random Number Generator können Sie sofort jede Anzahl zwischen einem Minimum und maximal Ihrer Wahl auswählen. Egal, ob Sie ein Giveaway, Lehrstatistiken oder ein freundliches Argument betreiben, es gibt Ihnen jedes Mal ein faires, unvoreingenommenes Ergebnis. Setzen Sie einfach Ihre Reichweite, wählen Sie, wie viele Zahlen Sie brauchen, und schlagen generieren.

Wie zu benutzen

  1. Geben Sie einen Mindestwert im Min-Feld ein (Standard ist 1).
  2. Geben Sie im Feld Max einen Maximalwert ein (Standard ist 100).
  3. Stellen Sie fest, wie viele Zahlen Sie auf einmal generieren möchten (bis zu 100).
  4. Klicken Sie auf Nummer generieren oder drücken Sie Leerzeichen oder Enter.
  5. Verwenden Sie die Schaltfläche Kopieren, um Ihre Ergebnisse in der Zwischenablage zu speichern.

Gemeinsame Nutzungen

  • Abholung eines Verlosungs- oder Giveaway-Siegers aus einer nummerierten Liste
  • Glückszahl Ideen für Lotterie oder Sweepstakes
  • Simulieren von Würfeln in Tischspielen, die ungewöhnliche Zahlenbereiche verwenden
  • Statistische Probenahmen in Klassenräumen oder Forschungsprojekten
  • Argumente festlegen, wenn niemand zustimmen kann — wer Kaffee kauft, zum Beispiel
  • Zuordnen von zufälligen Schülerzahlen oder Sitzpositionen in einem Klassenzimmer

Warum Spinnit verwenden

Spinnit's Generator produziert sofortige Ergebnisse in Ihrem Browser ohne Setup oder Konto erforderlich. Alle Zufälligkeit geschieht lokal, so dass nichts, das Sie eingeben, jemals an einen Server gesendet wird. Die Ergebnishistorie verfolgt Ihre letzten zehn Ausgänge, so dass Sie ohne Notizen vergleichen können. Funktioniert perfekt auf Handy, Tablet und Desktop.

Beliebte Bereiche

Springen Sie gerade in einen gemeinsamen Bereich: 1–2 · 1–5 · 1–6 (Indizes) · 1–10 · 1–20 (D20) · 1–25 · 1–50 · 1–100 · 1–1000 · 1–1,000,000.

Häufig gestellte Fragen

Ist das Ergebnis wirklich zufällig?

Ja. Der Generator verwendet den eingebauten Browser Ihres Browsers Math.random() Funktion, die unvorhersehbare Ergebnisse hervorbringt, die von Systementropie gesät werden. Es ist nicht möglich, die nächste Anzahl vorherzusagen.

Kann ich mehrere Zahlen gleichzeitig generieren?

Ja. Setzen Sie das Feld "Wie viele Zahlen?" auf jeden Wert zwischen 1 und 100 und alle Ergebnisse werden zusammen erscheinen, getrennt von Kommas.

Ist dieses Tool kostenlos zu verwenden?

Ja, völlig kostenlos ohne Anmeldung erforderlich.

Arbeitet das auf Handy?

Ja, alle Spinnit-Tools sind mobil-first und arbeiten an jedem Gerät.
