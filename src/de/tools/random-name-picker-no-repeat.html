Random Name Picker – Keine Wiederholungen

Jeder Name wird einmal ausgewählt, bevor jemand zweimal ausgewählt wird

Die meisten Namenswähler wählen unabhängig — was bedeutet, dass jemand zweimal abgeholt werden kann, während andere nie abgeholt werden. Dieses Tool macht es richtig: es funktioniert durch die vollständige Liste in einer zufälligen Reihenfolge, und Niemand wird ein zweites Mal ausgewählt, bis der Zyklus abgeschlossen ist.

Wie es funktioniert

Im Innern ist es ein Fisher-Yates Schlämmchen. Auf dem ersten Tipp wird die Liste einmal randomisiert. Jeder nachfolgende Tape zeigt einfach den nächsten Namen in der gedämpften Reihenfolge. Wenn die Liste erschöpft ist, fordert das Tool Sie auf, zurückzusetzen (was reshuffles, so dass die zweite Runde eine andere Reihenfolge von der ersten ist).

Wo es passt

  • Kalter Anruf in der Klasse — jeder Schüler beantwortet zweimal
  • Präsentationsauftrag — faire Ordnung, keine "Ich bin schon gegangen" Argumente
  • Der Weihnachtsmann — assign giver → Empfänger ohne jede Zeichnung selbst
  • Drehrohre — Pflicht, Leseauftrag, täglicher Helfer
  • Zufälliger Interviewauftrag — faire Reihenfolge der Bewerber oder Bewerber

Nicht richtig?

Wenn Sie wollen, wählen Sie das können wiederholen (jeder Hahn unabhängig) Rad der Namen oder Schüler mit nicht-repeat unticked. Um die gesamte Liste in einem Klick zu schütteln und die Bestellung auf einmal zu sehen, verwenden Sie Liste Shuffler.

Häufig gestellte Fragen

Ist die Bestellung wirklich zufällig jedes Mal?

Ja. Ein frischer Fisher-Yates Shuffle läuft auf dem ersten Pick und auf jedem Reset, so ist die Bestellung unvoreingenommen und unterschiedlich jede Runde.

Was, wenn ich die Liste mittig bearbeite?

Bearbeiten der Liste setzt die Runde automatisch zurück. Dadurch wird ein versehentliches Picken von einer Stallschläuche verhindert, die nicht mit der sichtbaren Liste übereinstimmt.

Ist es das gleiche wie die Liste Shuffler?

Unter der Haube, ja — aber die Interaktion ist anders. Dieses Tool zeigt einen Namen zu einer Zeit (gut für Live-Klassenbenutzung). Die Liste Shuffler zeigt die komplette Liste auf einmal.
