Letzte Rollen

Die d100 - auch als prozentile Würfel oder d% - ist das Rückgrat jeder RPG, die auf prozentualen Chancen arbeitet. Rollen niedrig, erfolgreich; rollen hoch, scheitern (gewöhnlich). Jede Zahl von 1 bis 100 hat genau eine 1% Chance, so dass es die sauberste statistische sterben in Tischspiele.

Systeme, die d100 verwenden

  • Call of Cthulhu — jede Qualifikationsprüfung
  • Warhammer Fantasy / 40K Zoom — Kernmechanik
  • Rolemaster und RuneQuest
  • D& D 5e — Wilde magische Surge, zufällige Tabellen, magische Artikel Rarität
  • Irgendwelche "Rollen auf der zufälligen Begegnungstabelle" Moment

Wie d100 normalerweise physisch gerollt wird

Physikalische d100s sind tatsächlich zwei d10s: eine "Tens" sterben (00, 10, 20... 90) und eine "ones" sterben (0–9), summiert mit 00+0 Lesen als 100. Dieser Generator überspringt die Zeremonie und gibt Ihnen das letzte 1–100 Ergebnis direkt.

Sonstige Würfel

Versuch D10, D20, 2d6, 3D6, 4d6 niedrig, oder Vollständige Dice Roller.

Häufig gestellte Fragen

Ist der d100 Bereich 1–100 oder 0–99?

Die meisten modernen Systeme verwenden 1–100 mit 00 auf physikalische Würfel lesen als 100. Einige ältere Systeme (z.B. Basic Zooming Varianten) verwenden 0–99 für bestimmte Tabellen. Dieses Tool verwendet 1–100.

Ist das Rollen niedrig oder hoch besser?

Es hängt vom System ab. Call of Cthulhu und Warhammer wollen, dass Sie rollen unter Deine Fähigkeit. Zufällige Tabellen wollen typischerweise einen bestimmten Bereich. Überprüfen Sie immer, was Ihr System erwartet.

Kann ich mehrere d100s auf einmal rollen?

Ja. Stellen Sie die Zählung bis zu 100. Jede Rolle ist unabhängig, so dass Duplikate möglich und erwartet werden.
