Rad der Namen für den Klassenraum

Ein lehrerfreundliches Namensrad — plus Tipps, die tatsächlich funktionieren

Gepflegt
—

Ein Namensrad ist eines der einfachsten Lehrwerkzeuge, um zu Ihrer Routine hinzuzufügen – und eines der effektivsten für faire Studentenbeteiligung. Diese Seite gibt Ihnen einen schnellen Picker oben, und darunter eine praktische Anleitung, um ein Namensrad zu verwenden, ohne dass es in Ihrer Lektion Rauschen wird.

Warum ein Namensrad in der Klasse verwenden

  • Anzahl der Stimmen — ruhige Studenten werden so oft wie die Hand-Raiser aufgerufen
  • Reduzierter Widerstand — "das Rad hat dich ausgewählt" ist leichter zu akzeptieren als "Ich wähle dich"
  • Achtung — Studenten bleiben wachsam, weil jemand als nächstes
  • Pace — ein Hahn, eine Antwort, keine Warte auf die Hände
  • Datenerhebung — den Überblick behalten, wer beantwortet wird, um Muster zu erkennen

Drei Möglichkeiten, es gut zu nutzen

1. Der kalte Anruf. Stellen Sie eine Frage, halten Sie für zehn Sekunden Denken Zeit, dann Tippen Sie auf das Rad. Denkzeit ist nicht verhandelbar – ohne dass man "Ich weiß nicht" anstelle von echten Antworten bekommt.

2. Das Sicherheitsnetz. Lassen Sie den Schüler antworten, und wenn sie stecken bleiben, lassen Sie sie "über das Rad" zu einem Peer ihrer Wahl. Sie bleiben in der Kontrolle, aber die Aktivität geht weiter.

3. Der Präsentationsauftrag. Für Gruppenarbeit oder individuelle Präsentationen drehen Sie das Rad einmal pro Slot, um die Bestellung live einzustellen. Entfernt jedes "Sie gehen zuerst" Argument.

Drei häufige Fehler

  • Skipping der ausgewählten Schüler — wenn das Rad einen Namen nennt, begehen Sie es. Skipping bricht den Fairnessvertrag.
  • Verwenden Sie es für High-Stake-Fragen — niemals das Rad für öffentliche Kennzeichnungs- oder Verhaltensentscheidungen verwenden. Behalten Sie es.
  • Zurücksetzen vergessen — wenn Sie No-Repeat-Modus verwenden, zurücksetzen Sie nach jeder Lektion oder Klasse Dynamik skew.

Willst du das volle animierte Rad?

Der Picker oben ist absichtlich schnell - tippen Sie, fertig. Für die volle Spinnen-Animation, die Kinder genießen, die Hauptnutzung Rad der Namen. Auch nützlich: die Zufälliger Student Picker mit No-Repeat-Modus, die Team Picker für Gruppenarbeit und Liste Shuffler für eine einmalige zufällige Reihenfolge.

Häufig gestellte Fragen

Ist diese DSGVO-sicher für eine britische Schule?

Ja. Namen, die Sie einfügen, verlassen nie den Browser-Tab – kein Upload, kein Konto, keine Cookies, die Sie über Websites verfolgen. Das bedeutet, dass es in Bezug auf dieses Tool keine personenbezogene Datenverarbeitung unter DSGVO gibt.

Wird es an einem interaktiven Whiteboard arbeiten?

Ja. Das Werkzeug ist ansprechend und berührungsfreundlich. Für den saubersten Blick auf eine IWB drücken Sie F11 für Vollbild und verwenden Sie die Haupt Rad der Namen für die animierte Version.

Kann ich meine Klassenliste zwischen Lektionen speichern?

Derzeit nicht — aber Sie können eine Liste aus einer Notiz oder Tabellenkalkulation in einer Sekunde einfügen. Viele Lehrer halten eine "Class 7B roster" Notiz auf ihrem Telefon aus diesem genauen Grund.
