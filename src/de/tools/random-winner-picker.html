Random Winner Picker

Faire, transparente Ziehungen für Giveaways und Wettbewerbe

Gewinner
—

Wenn Sie einen Giveaway laufen und einen Gewinner fair wählen müssen? Fügen Sie Ihre Eintragsliste ein (eine pro Zeile), setzen Sie, wie viele Gewinner Sie wollen, und tippen Sie auf die Schaltfläche. Jeder Eintrag hat eine gleiche Chance, kein Eintrag wird zweimal in der gleichen Ziehung ausgewählt, und Sie können das Ergebnis als Beweis Screenshot. Kein Konto erforderlich.

Was als Eintragsliste einzufügen ist

  • In den Warenkorb — die Kommentarliste aus einem Abstreifer oder Export kopieren
  • Twitter/X Antworten — Kopieren Sie die @Handle von jedem, der eingetragen ist
  • E-Mail Adressen — aus einem Anmeldeformular oder einer Mailingliste
  • Ticketnummern — für eine Verlosung
  • Kunden-IDs — für eine Treuebelohnung

Halten Sie Ihre Ziehung transparent

Für öffentliche Werbegeschenke auf sozialen Medien benötigen die meisten Plattformen die Ziehung, um überprüfbar zu sein. Die Standardpraxis:

  1. Melden Sie die Eingaberegeln und das Schließdatum vorn an
  2. Einträge schließen — die Liste nach dem Schließen nicht bearbeiten
  3. Screen-Record oder Screenshot der Picker zeigt die vollständige Eintragsliste und das Ergebnis
  4. Geben Sie das Ergebnis mit dem Datum und der Anzahl der Einträge

Duplikate Handhabung

Standardmäßig hält das Tool Duplikate – manchmal wollen Sie Einträge gewichtet durch Eingabenummer. Tick Entfernen Sie doppelte Einträge zu kollabieren wiederholt, so dass jeder einzigartige Griff nur eine Chance hat.

Andere Werkzeuge

Auch nützlich: Wählen Sie einen zufälligen Namen, Lotterie Picker, Rad der Namen, Randnummer 1–1000.

Häufig gestellte Fragen

Ist die Messe?

Ja. Jeder Eintrag hat genau die gleiche Chance ausgewählt zu werden. Das Tool verwendet den unvoreingenommenen Zufallszahlengenerator des Browsers und zeigt Ihnen die volle Eingangszahl vor jeder Ziehung.

Kann der gleiche Eintrag zweimal in einer Ziehung gewinnen?

Nein. Bei der Auswahl von mehreren Gewinnern entfernt das Tool jeden Gewinner aus dem Pool, bevor Sie den nächsten ziehen – so kann kein einziger Eintrag zwei Preise in der gleichen Ziehung gewinnen.

Befolgt dies Instagram / Facebook-Geschenkregeln?

Das Werkzeug handhabt die Ziehung selbst — die Einhaltung hängt davon ab, wie Sie das Giveaway ausführen. Immer freigebende Verantwortungsträger von der Plattform, beinhalten Förderregeln und folgen der Werbepolitik jeder Plattform.
