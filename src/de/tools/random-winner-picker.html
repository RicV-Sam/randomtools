Random Winner Picker

Fair, transparent draws for giveaways and competitions

winner
—

Running a giveaway and need to pick a winner fairly? Paste your entry list (one per line), set how many winners you want, and tap the button. Every entry has an equal chance, no entry is picked twice in the same draw, and you can screenshot the result as proof. No account required.

What to paste as an entry list

  • Instagram comments — copy the comment list from a scraper or export
  • Twitter/X replies — copy the @handles of everyone who entered
  • Email addresses — from a signup form or mailing list
  • Ticket numbers — for a raffle draw
  • Customer IDs — for a loyalty reward

Keeping your draw transparent

For public giveaways on social media, most platforms require the draw to be verifiable. The standard practice:

  1. Announce the entry rules and closing date up front
  2. Close entries — don't edit the list after closing
  3. Screen-record or screenshot the picker showing the full entry list and the result
  4. Post the result with the date and the number of entries

Duplicate handling

By default the tool keeps duplicates — sometimes you want entries weighted by submission count. Tick Remove duplicate entries to collapse repeats so each unique handle has one chance only.

Frequently Asked Questions

Is the draw fair?

Yes. Every entry has exactly the same chance of being picked. The tool uses the browser's unbiased random number generator and shows you the full entry count before each draw.

Can the same entry win twice in one draw?

No. When picking multiple winners, the tool removes each winner from the pool before drawing the next — so no single entry can win two prizes in the same draw.

Does this comply with Instagram / Facebook giveaway rules?

The tool handles the draw itself — compliance depends on how you run the giveaway. Always release entrants of responsibility from the platform, include eligibility rules, and follow each platform's promotional policy.
