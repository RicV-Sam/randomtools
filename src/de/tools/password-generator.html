Sicherheitstipps

  • Verwenden Sie ein einzigartiges Passwort für jedes Konto
  • Passwörter in einem Passwort-Manager wie Bitwarden oder 1Passwort speichern
  • Mögliche Zwei-Faktor-Authentifizierung aktivieren
  • Kennwörter niemals per E-Mail oder Chat teilen

Der Password Generator erstellt kryptographisch zufällige Passwörter mit der sicheren zufälligen API Ihres Browsers – kein vorhersehbarer Algorithmus. Sie steuern die Länge (6 bis 64 Zeichen) und welche Zeichentypen enthalten. Das Stärkemessgerät aktualisiert live, so dass Sie genau sehen können, wie sicher jedes Passwort vor dem Kopieren ist.

Wie zu benutzen

  1. Ziehen Sie den Längenschieber, um Ihre gewünschte Passwortlänge (6–64 Zeichen) einzustellen.
  2. Großbuchstaben, Kleinbuchstaben, Zahlen und Symbole ein- oder ausschalten.
  3. Aktivieren Sie "Exclude mehrbiguous" um Zeichen wie 0, O, l und 1 zu entfernen, die ähnlich aussehen.
  4. Klicken Sie auf Passwort generieren oder tippen Sie auf das Ergebnisfeld, um ein neues Passwort zu erstellen.
  5. Klicken Sie auf Passwort kopieren, um es direkt auf Ihre Zwischenablage zu speichern.

Gemeinsame Nutzungen

  • Erstellen von starken Passwörtern für neue Online-Konten
  • Generieren von API-Schlüsseln oder geheimen Token für Entwicklungsprojekte
  • Sicherheitsbewusstseinstraining in Klassenräumen oder Arbeitsplätzen
  • Wiederverwenden von schwachen oder wiederverwendeten Passwörtern ein Konto zu einem Zeitpunkt
  • Einstellung temporärer Passwörter für neue Benutzer in einer Organisation
  • Generieren von zufälligen Strings für Test- oder Codemuster

Warum Spinnit verwenden

Passwörter werden vollständig in Ihrem Browser mit Hilfe von crypto.getRandomValues() — sie werden niemals überall übertragen, gespeichert oder eingeloggt. Das Tool ist kostenlos, sofort und funktioniert auf mobile. Es ist kein Konto oder eine E-Mail-Adresse erforderlich.

Häufig gestellte Fragen

Sind Passwörter irgendwo gespeichert oder übertragen?

Nein. Jedes Passwort wird lokal in Ihrem Browser mit der Web Cryptography API generiert. Nichts verlässt Ihr Gerät – keine Daten werden jemals an einen Server gesendet.

Wie lange sollte mein Passwort sein?

Sicherheitsexperten empfehlen mindestens 16 Zeichen für die meisten Konten. Für hochwertige Konten wie Banking oder E-Mail sind 20+ Zeichen mit Symbolen ideal. Der Kraftmesser führt Sie.
