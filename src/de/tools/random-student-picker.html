Ein zufälliger Student Picker ist der ruhigste Weg, um die Klasse anzurufen. Keine Hände auf, keine Favoriten, keine Vermutung, wer still war — das Werkzeug wählt, und jeder nimmt das Ergebnis an. Fügen Sie Ihren Rouster einmal ein, tippen Sie einmal pro Frage, und die "Nicht zweimal wählen" Option sorgt dafür, dass jeder Schüler eine Runde bekommt, bevor jemand wieder gefragt wird.

Wie Lehrer es benutzen

  • Kalte Berufung — eine Frage stellen, lassen Sie das Werkzeug wählen, die Antworten
  • Lies laut — wählen, wer den nächsten Absatz liest
  • Präsentationen — die Vorlageentscheidung rechtlich
  • Start-Aktivitäten — wählen Sie einen Schüler, um die gestrige Unterrichtsstunde wieder zu entkleiden
  • Verhaltensneutrale Anrufung — entfernt die Wahrnehmung, dass Sie bestimmte Studenten ansprechen

Tipps für Projektoren

Der gewählte Name wird in großem Text wiedergegeben, so dass er von der Rückseite des Raumes liest. Für eine noch größere Anzeige drücken Sie F11, um Vollbild zu gehen. Namen, die im Rouster eingegeben werden, werden nie irgendwo gesendet – das gesamte Tool läuft in Ihrem Browser.

Willst du ein visuelles Rad?

Für eine spinnende animierte Version, die Kinder lieben, verwenden Sie die Rad der Namen. Es unterstützt die gleiche Name-Liste Eingabe mit einer richtigen Rad-Animation. Versuchen Sie auch die No-Repeat Name Picker, die Team Picker für Gruppenarbeit oder Liste Shuffler einen Ritter in einen Schlag zu schütteln.

Häufig gestellte Fragen

Ist meine Klassenliste irgendwo gespeichert?

Nein. Die Namen leben nur in diesem Browser-Tab. Schließen Sie die Registerkarte und sie sind weg - nichts wird an einen Server gesendet, und kein Konto ist erforderlich.

Was passiert, wenn jeder Schüler ausgewählt wurde?

Wenn "nicht den gleichen Schüler zweimal auswählen" ist angekreuzt, das Tool kündigt die Liste vollständig an und lässt Sie tippen Zurück zur Übersicht wieder vom vollen Rouster zu starten.

Kann ich das für eine Ganzschulversammlung verwenden?

Ja — es gibt keine Begrenzung auf der Rousterlänge, und der Picker läuft sofort auch auf einer Liste von mehreren hundert Namen.
