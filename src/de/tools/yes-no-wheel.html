Ja / Kein Rad

Drehen Sie das Rad — lassen Sie Schicksal entscheiden

Das Ja No Wheel gibt Ihnen eine befriedigende Spinnenanimation, die entweder auf Ja oder Nein landet - oder vielleicht, wenn Sie eine Drei-Wege-Split bevorzugen. Sie können den Modus anpassen, um das Ergebnis auf eine Antwort zu gewichten, was es vielseitiger macht als ein einfacher Münz-Flip. Es ist der lustigste Weg, eine schnelle Entscheidung zu treffen oder eine Krawatte zu brechen.

Wie zu benutzen

  1. Wählen Sie Ihren bevorzugten Modus aus dem Dropdown (Ja/Nein, Ja/Nein/Maibe, Wahrscheinlich Ja, oder wahrscheinlich Nein).
  2. Klicken Sie auf das Rad drehen oder tippen Sie auf die Leinwand direkt.
  3. Warten Sie auf das Rad zu langsam und landen auf Ihre Antwort.
  4. Drehen Sie wieder so oft wie Sie möchten – es gibt keine Grenze.

Gemeinsame Nutzungen

  • Entscheiden, ob Sie einen Takeaway bestellen oder heute kochen
  • Bruch in Gruppenentscheidungen, bei denen niemand zustimmen kann
  • Unterrichtsaktivitäten für zufälliges studentisches Engagement
  • Herausforderungen der täglichen Entscheidung für Content-Autor und Streamer
  • Legen freundliche Argumente zwischen Kollegen oder Hausgenossen
  • Kinderspiele und Party-Aktivitäten, bei denen ein Spaß-Spin zur Atmosphäre hinzukommt

Warum Spinnit verwenden

Die gewichteten Modi — Wahrscheinlich Ja und wahrscheinlich Nein — machen diese vielseitiger als ein Standard-Münzen-Flip, wenn Sie eine Nudge in einer bestimmten Richtung wollen. Die Radanimation ist glatt und ansprechend auf allen Bildschirmgrößen. Keine Installation, kein Login und keine Daten werden jemals irgendwo gesendet.

Häufig gestellte Fragen

Kann ich eine Option hinzufügen?

Ja. Wählen Sie "Ja / Nein / Vielleicht" aus dem Modus Dropdown und das Rad wird gleich in drei Segmente aufgeteilt.

Kann ich das Ergebnis gegen Ja oder Nein gewichten?

Ja. Die "wahrscheinlich Ja" und "wahrscheinlich Nein" Moden geben eine 70% Chance auf ein Ergebnis und 30% auf das andere, so dass das Rad noch etwas Spannung hat.

Ist dieses Tool kostenlos zu verwenden?

Ja, völlig kostenlos ohne Anmeldung erforderlich.

Arbeitet das auf Handy?

Ja, alle Spinnit-Tools sind mobil-first und arbeiten an jedem Gerät.
