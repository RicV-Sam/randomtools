Über uns

Zufallstools für alle

Spinnit ist eine kostenlose Sammlung von Zufallsgeneratoren — gebaut fürs Web. Keine Konten. Keine Downloads. Kein Schnickschnack. Tool öffnen, Tool nutzen — auf jedem Gerät, überall auf der Welt.

Unsere Mission

🆓
Immer kostenlos Jedes Tool auf Spinnit ist dauerhaft und komplett kostenlos.
🚫
Ohne Anmeldung Kein Konto, keine E-Mail, kein Passwort — einfach öffnen und loslegen.
📱
Läuft mobil Mobile-first entwickelt und auf allen Bildschirmgrößen getestet.
🌍
Weltweit schnell Vollständig statisch — keine Server-Rundreisen, überall blitzschnell.

Die Tools

Spinnit hat 13 Kerntools — Zufallszahlen-Generator, Würfel, Münzwurf, Team-Picker, Namensrad, Passwort-Generator und mehr — plus 20 spezielle Presets für konkrete Aufgaben (4W6 niedrigsten streichen für D&D, einen Schüler ohne Wiederholung ziehen, Gewinner bei Gewinnspielen auslosen und so weiter).

Wer steckt dahinter?

Spinnit wird von einem kleinen, unabhängigen Team in England gebaut und gepflegt. Wir schreiben den Code selbst, testen jedes Tool auf den Handys, die wir tatsächlich benutzen, und lesen jedes Feedback, das reinkommt. Kein VC, keine Agentur, keine SEO-Farm — nur eine kostenlose Website, die wir selbst haben wollten.

Wenn du eine Idee für ein neues Tool hast, einen Bug gefunden hast oder eine Korrektur vorschlagen möchtest, schreib uns an hello@spinnit.site oder nutze das Kontaktformular.

Weitere Tools in Arbeit

Wir arbeiten an weiteren Tools — unter anderem einem Zitat-Generator, einem Emoji-Picker und einem Zufallsdatum-Generator. Hast du einen Vorschlag? Schreib uns eine Zeile an hello@spinnit.site — wir hören gerne, was du brauchst.

Wie es gebaut ist

Spinnit ist mit reinem HTML, CSS und JavaScript gebaut — keine Frameworks, keine Build-Tools, keine Tracking-Bibliotheken. Jedes Tool läuft komplett in deinem Browser. Nichts, was du eingibst oder erzeugst, wird irgendwohin gesendet. Die gesamte Seite ist offen und überprüfbar.

  • Keine Analytics und kein Tracking (standardmäßig — kann sich mit Einwilligung ändern)
  • Keine Konten, keine gespeicherten personenbezogenen Daten
  • Keine externen JavaScript-Abhängigkeiten
  • Als PWA auf Handy und Desktop installierbar
