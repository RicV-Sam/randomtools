Über uns

Zufällige Werkzeuge für alle

Spinnit ist eine kostenlose Sammlung von zufälligen Generatoren für das Web gebaut. Keine Konten. Keine Downloads. Kein Unsinn. Öffnen Sie einfach ein Werkzeug und verwenden Sie es – auf jedem Gerät, überall auf der Welt.

Unsere Mission

🆓
Immer kostenlos Jedes Werkzeug auf Spinnit ist völlig kostenlos zu verwenden, für immer.
🚫
Keine Anmeldung Kein Konto, keine E-Mail, kein Passwort – einfach öffnen und verwenden.
📱
Werke auf dem Handy Entwickelt mobil-first und auf allen Bildschirmgrößen getestet.
🌍
Global Schnelle weltweit — voll statisch, keine Server-Rundfahrten.

Die Werkzeuge

Spinnit hat 13 Kernwerkzeuge — Random Number Generator, Dice Roller, Coin Flip, Team Picker, Wheel of Names, Password Generator und mehr — plus 20 zielgerichtete Presets für bestimmte Jobs (Rolling 4d6-Drop-lowest for D&D, Picking ein Klassenzimmer Student ohne Wiederholungen, Zeichnung ein Giveaway-Sieger, und so weiter).

Wer steckt dahinter?

Spinnit wird von einem kleinen unabhängigen Team mit Sitz in England gebaut und gepflegt. Wir schreiben den Code selbst, testen jedes Tool auf den Handys, die wir tatsächlich besitzen, und lesen jedes Feedback, das kommt. Kein VC, keine Agentur, keine SEO Farm — nur eine kostenlose Dienststelle, die wir wollten.

Wenn Sie eine Idee für ein Werkzeug haben, sollten wir bauen, einen Fehler, den wir beheben sollten, oder eine Korrektur zu machen — schreiben Sie uns an hello@spinnit.site oder durch Kontaktformular.

Weitere Werkzeuge kommen bald

Wir arbeiten an mehr Tools, einschließlich eines zufälligen Zitatgenerators, zufälligen Emoji-Picker, zufälligen Datumsgenerator und mehr. Hast du einen Vorschlag? Lass uns eine Zeile hello@spinnit.site - wir würden gerne hören, was Sie brauchen.

Wie es gebaut wird

Spinnit ist mit reiner HTML, CSS und JavaScript — keine Frameworks, keine Build-Tools, keine Tracking-Bibliotheken. Jedes Tool läuft vollständig in Ihrem Browser. Nichts, das Sie tippen oder generieren, wird jemals irgendwo gesendet. Die gesamte Website ist offen und auditierbar.

  • Keine Analytik oder Tracking (nicht standardmäßig — kann mit Zustimmung ändern)
  • Keine Konten oder personenbezogene Daten gespeichert
  • Keine externen JavaScript Abhängigkeiten
  • Installierbar als PWA auf Mobil und Desktop
