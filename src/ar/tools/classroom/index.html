أدوات رانددوم

بسرعة، أدوات خاصة للمدرسين الذين يحتاجون إلى اختيار الطلبة، أو إنشاء مجموعات، أو وضع قوائم، أو تنظيم ألعاب دراسية عادلة بدون توقيع أو تحميل.

المعلمون

راندوند بيكر

قدموا قائمة الطبقة واختاروا الطلبة بشكل عادل، مع سلوك غير متكرر اختياري.

الصفوف

عجلة طالبة بسيطة للمكالمات الباردة، والمبارات والمشاركة السريعة

فريق راندوم بيكر

:: تقسيم الطلاب إلى فرق عشوائية متوازنة لـ PE، والعمل الجماعي، والألعاب المدرسية.

قائمة المتثاقل

اربطي قائمة أو قائمة عمل أو ترتيب عرض في ثواني

مولدات الأسماء العشوائية

وضع أسماء خيالية لكتابة العجلات والأمثلة وأنشطة لعب الأدوار.

العدد المستخدم

العدد 1-25

اختيار عدد الطلاب بسرعة في قائمة نموذجية للصفوف الدراسية.

العدد 1-10

استخدام المجموعات، والمحطات، واستعراض الأسئلة وخيارات الأنشطة السريعة.

عدد المولدات

وضع أي نطاق للصفوف الدراسية وتوليد أرقام أو أعداد كثيرة.

دليل التعليم

كيف تختار فرق الراندوم بشكل عادل

ثلاث طرق لتقسيم المجموعات بدون أن يختار الكابتن آخر
