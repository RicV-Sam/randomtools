# Baseline Tracking Setup (Week 1)

## Search Console Baseline
1. Open Performance report and filter by URL contains `/ai/`.
2. Export last 28 days for pages and queries.
3. Save exports in your ops folder and use `weekly-scorecard.md` for rollups.

## Required Views
- Page clusters:
  - `/ai/tools/`
  - `/ai/compare/`
  - `/ai/best/`
  - `/ai/blog/`
- Metrics: clicks, impressions, CTR, average position.

## Weekly Routine
1. Pull 7-day and 28-day data.
2. Update cluster and top-page rows in the scorecard.
3. Mark winners and underperformers.
4. Choose 2 pages for refresh.
5. Record publication/distribution outputs.
